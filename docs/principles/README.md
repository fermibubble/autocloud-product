# Principles

The autonomous-agent principles doc set: philosophy → application →
commercial argument → adversarial review. Extends the Rollout Reviewer
Team Standard v2.0 ("Trustworthy Autonomy and Defensible Product
Advantage for Rollout Reviewers").

| Doc | What it is | Read it when |
|---|---|---|
| [01-principles-of-trustworthy-autonomy.md](01-principles-of-trustworthy-autonomy.md) | **The main doc.** Nine principles of trustworthy autonomy — the standard's four, deepened, plus five a platform of agents forces into existence. Philosophical grounding, real-world cases, engineering contracts, and a nine-question review card. | Designing any agent capability; reviewing any autonomy expansion |
| [02-rollout-reviewer-tenets.md](02-rollout-reviewer-tenets.md) | The principles applied to the Rollout Reviewer on Ensemble: ten quotable tenets with their enforcement mechanisms, the contribution contract, an honest gap register (G1–G8), and staged autonomy gates. | Contributing to the reviewer; arguing about a change |
| [03-value-and-moat.md](03-value-and-moat.md) | The commercial argument: commodity baseline, the two-layer offer (platform × vertical), the moat stack mapped to real mechanisms with maturity grades, the outcome flywheel, packaging along the autonomy dial, the DIY-baseline proof plan, erosion risks, four-quarter sequence. | Roadmap and positioning discussions |
| [04-independent-critique.md](04-independent-critique.md) | The adversarial review this set was subjected to before publication: fact-check verdicts, codebase-fidelity findings, logic critique — what was corrected, what was softened, what remains open. | Deciding how much to trust docs 01–03 |

House rules for this folder: every real-world claim survives an
independent fact-check or gets hedged/removed; every "the system does X
today" claim cites a mechanism that exists in the repos; aspiration is
labeled as roadmap, never narrated as implementation. Doc 04 is the
audit trail for those rules.
